# 各格式网页只读支持情况

目标：**仅预览，不编辑、不修改原文件**，浏览器直接访问，手机Safari兼容。

| 后缀 | 能否网页预览 | 方案说明 | 备注 |
| --- | --- | --- | --- |
| `.py` `.json` `.jsonl` `.md` `.txt` `.yaml` `.yml` `.csv` | ✅ | 直接读取文本，前端渲染 | py/json/jsonl/yaml做代码高亮；md用markdown渲染库；csv简单表格渲染 |
| `.pdf` | ✅ | pdf.js | 完整翻页、缩放、搜索，手机可用 |
| `.docx` | ✅ | docx‑preview | 现代word，大部分排版保留 |
| `.doc` | ⚠️ | 很差 | 老二进制doc，前端几乎没有靠谱解析库；建议提示：请转docx预览 |
| `.xlsx` | ✅ | SheetJS(xlsx库) | 可以渲染表格，只读展示单元格内容，图表会丢失 |
| `.pptx` | ⚠️ | 有限支持 | SheetJS只能读文本内容，样式、动画、图片丢失，只能看文字摘要，做不到还原PPT版式 |
| `.png` `.jpg` `.jpeg` `.svg` | ✅ | 浏览器原生`<img>` | 直接渲染图片，支持缩放 |
| `.mp4` | ✅ | HTML5 `<video>` | 原生播放，seek拖拽正常 |
| `.wav` | ✅ | HTML5 `` | 音频直接播放 |
| `.html` | ✅ | 两种模式：①直接展示源码；②iframe渲染（有安全风险，开源项目建议默认展示源码） | **不要默认iframe渲染外部html，有XSS隐患** |

## 总结现实边界（写进readme很重要）

1. **完美支持**：py/json/jsonl/md/txt/yaml/yml/csv / pdf / docx / xlsx / png/jpg/jpeg/svg / mp4 / wav
2. **弱支持**：
   - `.doc`：老格式，**不做预览，提示用户转docx**
   - `.pptx`：只能提取文本表格，无法还原幻灯片样式，仅文字预览
3. **`.html`：默认展示源代码，关闭iframe渲染，规避安全问题**

## 架构小提示（适配你的cross‑read项目）

- 后端（FastAPI/Flask）只做：遍历本机目录、返回文件二进制/文本，**不做 heavy转码**；
- 所有解析渲染全部丢前端浏览器完成，电脑服务压力很小；
- 只做**只读**：禁止任何写、删除、上传接口，安全简单。
